# Optibook competition resources

## Reading order for a CLI agent

1. `text/setup_faq_overview.md` — the setup instructions, both FAQ sections, and introduction pasted in the conversation, with wording preserved, including copied UI labels such as `svg`.
2. `text/api_reference.txt` — the complete uploaded API reference, preserved byte for byte from `Pasted text(20261123-182114).txt`.
3. `images/` — all four supplied image attachments, preserved byte for byte under their original filenames.

`ALL_TEXT.md` concatenates the two text sources in that order, with explicit source boundaries for convenient ingestion. It duplicates the individual source files; do not treat it as additional documentation.

## Scope and provenance

This package contains the pasted text and the five files attached to this request (one text file and four images). It is not a verified complete export of https://2026-docsoc.optibook.net/. Links in the supplied text are retained; their destinations were not downloaded. Images remain images rather than OCR transcripts. Example prices, positions, and limits are source examples, not verified live competition settings.

This README, the source-boundary labels in ALL_TEXT.md, and the checksum manifest are packaging additions; the source documentation has not been summarized or rewritten.

`manifest.json` records byte counts and SHA-256 hashes for all other package files.
